Toda fotografía del sistema pasa por aquí — nunca un `<img>` suelto.

```jsx
<PhotoFrame src="/contenido/proyectos/01/portada.jpg" ratio="3 / 2" caption="Serie nocturna" veil="soft" />
```

La veladura no es decorativa: existe para que el texto blanco encima siga siendo legible.
Sin texto encima, use `veil="none"`.
